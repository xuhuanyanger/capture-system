# 硬件能力确认清单

当前主平台目标 RK3576，配置示例登记 ICM45686 和 AP6256；型号及接口能力以实际 BOM、板卡版本和 SDK 为准。

| 项目 | 必须登记及实测 |
|---|---|
| 相机 | 型号、五路拓扑、CSI/USB 接口、驱动版本、稳定设备 ID、像素格式、stride、曝光时间戳语义 |
| 同步 | 同步源器件准确型号、CAP0 含义、引脚/电平/频率、触发扇出、Trigger ID 来源、示波器测量 |
| 编码 | MPP/内核版本、并行路数、profile/level、分辨率帧率、缓冲导入能力 |
| IMU | 总线、ODR、FIFO 深度、计数位宽、FSYNC 支持、量程、轴向、安装外参及标定 |
| 音频 | ALSA 设备、采样率、通道、时钟源、硬件时间戳和 xrun 行为 |
| 存储 | 介质、文件系统、容量、持续写速、同步延迟、掉电行为 |
| 电源/散热 | 峰值功耗、电池状态来源、低压阈值、散热及热降频阈值 |
| 无线/蓝牙 | 芯片/固件、并发模式、控制协议、绑定机制、断连恢复 |

udev 按稳定硬件身份映射设备，禁止仅依赖易变化的 /dev/videoN 顺序。硬件保密资料单独管理，仓库记录可追踪版本及访问位置。未确认项不得在生产配置中隐式补默认值。
