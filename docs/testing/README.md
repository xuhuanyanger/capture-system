# 验证与验收

## 主机持续验证

运行 cmake --preset host-test、cmake --build --preset host-test、ctest --preset host-test。配置示例由 Python 标准库验证器执行结构及关键约束检查；它不是运行时配置加载器。CI 不证明硬件采集可用。

## 板端验收矩阵

| 场景 | 检查内容 | 通过条件 |
|---|---|---|
| 单路/五路采集 | fps、序号、编码、持续写速、CPU/RSS | 达到产品批准的帧率及丢帧预算 |
| 曝光同步 | 触发与曝光信号、光学事件 | p95/p99/max 均符合批准阈值 |
| 视频/IMU/音频关联 | 已知物理事件、延迟与漂移 | 分别符合各模态阈值 |
| 慢盘/磁盘满/写失败 | 队列、错误、收尾、完成标记 | 无死锁、不伪造成功、缺失可定位 |
| 相机断开/编码阻塞 | 超时、反向清理、状态转换 | 有界时间进入终态 |
| 断网/慢预览/上传失败 | 录像进度、重连、退避 | 不拖住录像，重试状态可恢复 |
| 进程终止/断电 | 随机阶段终止、清单/分段恢复 | 已提交任务可验证，未提交可识别 |
| 长稳/热/电源 | 目标最长时长、内存趋势、降频 | 无持续泄漏，异常按策略收尾 |

所有数值阈值、目标运行时长和硬件条件待产品与板端实测确认；阈值缺失表示未验收，不表示通过。结果记录主板/BOM、软件/SDK、配置摘要、工具、采样量、持续时间、误差分布和原始证据位置。模拟数据源必须支持时间跳变、计数回绕、迟到、丢帧和 FIFO 溢出，以便主机重复测试。
