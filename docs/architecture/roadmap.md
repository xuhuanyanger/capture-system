# 实现与交付顺序

1. 确认硬件清单、同步目标、任务时长、数据完整性和故障策略。
2. 实现单路 V4L2 → MPP → 分段存储，保留帧索引；验证正常停止和失败回滚。
3. 扩展五路，完成资源预算、队列及缓冲所有权测量。
4. 实现时间映射、触发事件、IMU FIFO 与 ALSA，并验证实际物理事件关联。
5. 实现断电恢复、磁盘满、设备断开、超时与同步失锁处理。
6. 接入控制 API、预览、上传持久化队列，再依据确认后的硬件和协议实现蓝牙及网页。

每阶段交付可运行程序、配置、自动测试和板端证据。交付包记录应用 commit、SDK/内核/设备树版本、依赖版本及校验和。MediaMTX 与 rclone 固定经验证版本，保留许可证信息；当前尚无锁定清单，部署者必须显式提供并验证二进制。

后续实现 install/打包规则、capture-service systemd 单元、非 root 设备权限、日志轮转和诊断包。诊断包只收集脱敏配置、版本、指标和错误摘要。升级保留配置迁移与回滚路径，不自动覆盖任务数据。
