# 任务状态机与故障处理

## 状态转换

IDLE → PREPARING → READY → RECORDING → STOPPING → COMPLETED。
PREPARING / READY / RECORDING 出现不可恢复故障时进入 STOPPING，尽力收尾后进入 FAILED。STOPPING 收尾超时也进入 FAILED，并保留可恢复目录。终态经显式释放后回到 IDLE；同一时间只允许一个活动任务。

PREPARING 校验配置、标定版本、设备能力、同步状态、磁盘可写性和剩余空间，并预分配资源。部分初始化失败按相反顺序回滚。READY 表示资源就绪，不代表已有同步合格数据。RECORDING 以实际首个有效数据记录开始，不能用 API 请求到达时间替代。

STOPPING 拒绝新数据、停止采集、排空编码与存储、封闭分段、写清单并执行持久化协议。每一步设置截止时间。预览和上传退出不能无限阻塞录像收尾。

## 命令与并发

命令包括 request_id、task_id、预期状态和配置摘要。相同 request_id 与相同请求返回原结果；相同 ID 的不同请求返回冲突。重复停止返回当前收尾或终态。运行中禁止改变设备映射、采样率、分辨率、编码及时间域；预览订阅与上传限速可独立调整。

总控是唯一状态写入者；模块通过事件上报。API 取消等待不等于取消已提交任务。进程崩溃后的请求去重依赖持久化命令记录，尚未实现前不得承诺跨重启幂等。

## 故障策略

| 故障 | 默认处理 |
|---|---|
| 相机断开、录像队列溢出、编码超时 | 收尾为 FAILED，记录流和缺失区间 |
| 磁盘满或写失败 | 停止采集，尽力收尾，禁止创建完成标记 |
| 同步失锁或超差 | 按任务配置停止或显式降级，记录质量区间 |
| 预览断线 | 重连，录像继续 |
| 上传失败 | 持久化退避重试，录像继续 |
| 温度或供电异常 | 根据经硬件确认的阈值收尾；不臆造阈值 |

启动扫描未提交任务，进入恢复流程；不得自动续写旧任务或将其标为正常完成。watchdog 观察采集进度、持久化进度和总控心跳，而非只检查进程存在。
